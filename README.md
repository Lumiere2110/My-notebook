# My notebook

ボックス・フォルダ・メモファイルでメモを整理して、ページに自由に書き込めるノートサイトです。

- サイト: https://lumiere2110.github.io/My-notebook/

## しくみ

```
〇〇ボックス            … 名前は自由（「仕事」と入れると「仕事ボックス」）
 ├ すべてのフォルダ     … ボックスの中のメモファイルをまとめて表示
 ├ フォルダ             … ボックスの中にいくつでも作れる
 │  └ メモファイル      … 名前を付けられる。中身は複数のページ
 │      └ ページ        … テキストボックス・付箋・画像・手書きを自由に配置
```

## できること

- **ボックス**: 左のサイドバーから作成・切り替え。名前の変更・削除
- **フォルダ**: ボックスの中に作成。「すべてのフォルダ」でボックス内のメモファイルを全部見られます
- **メモファイル**: 名前と用紙を選んで作成。名前の変更・別のフォルダへ移動・コピー・削除。一覧ではページの縮小表示が出ます
- **ゴミ箱ボックス**: 削除したボックス・フォルダ・メモファイルはここに入ります。「元に戻す」「完全に削除」「ゴミ箱を空にする」ができます
- **ページ**: 追加・複製・並べ替え・削除
- **用紙**: 白紙 / 罫線 / 細い罫線 / 余白付き罫線 / 2段罫線 / 方眼 / 細かい方眼 / 大きい方眼 / ドット / 縦罫線 / コーネル / ToDo / 週間予定 / 五線譜 / 原稿用紙。紙の色8色、縦向き・横向き。すべてのページにまとめて適用もできます
- **ツール**（ツールの欄は左端のつまみ ⠿ をドラッグすると好きな場所に動かせます。浮かせた欄は縦並び・横並びを切り替えられ、× かつまみのダブルクリックで元の場所に戻ります）
  - 選択: 置いたものや線・図形をクリックで選んでドラッグで移動、右下の丸で大きさを変更。回転・前面へ・背面へ・複製・固定。選ぶと出る赤いゴミ箱ボタン（または Delete キー）で削除
  - 範囲選択: なぞった線を周にして（途中で切れていたら始点と終点を結んで）、その中に少しでも入っているものを全部選びます。選んだものは色の変更・回転（ハンドルか ±15°・90°）・拡大縮小・移動・複製・削除・**固定**。固定したものは解除するまで動かしたり消したりできません
  - テキストボックス: クリックした場所に置いて文字を入力（大きさ4段階）。横書き・**縦書き**を選べます（付箋も縦書きにできます）。選択ツールのままページをダブルクリックしても置けます
  - 付箋: 18色。選ぶと右に出る緑の矢印ボタンを別の付箋までドラッグ（または「矢印でつなぐ」を押してつなぐ先をクリック）すると矢印でつなげます。矢印をクリックすると、一方向・双方向・線だけ、向きの反転、補足文字（線のまん中に表示）、色・太さ・点線を変えられます。付箋を動かすと矢印もついてきます
  - ペン（5段階の太さ）/ マーカー（4段階）で手書き。**定規モード**では描き終えた線を、直線（45°にそろえる）・四角・三角などの多角形・円に整えます。それ以外の線は、曲がっている所はなめらかな曲線に、急に曲がる所はとがった角にします。Shift を押しながら描くと15°ずつの直線
  - 図形: 四角・角丸・円・三角・ひし形・星・直線・矢印。色・太さ・塗り（なし・うすく・塗る）を選んでドラッグで描きます（Shift で正円・正方形、直線は15°ずつ）。クリックだけでも置けます
  - 消しゴム: 太さ4段階。「部分消し」はなぞった部分だけ、「線ごと」はふれた線をまるごと消します
  - 画像: ボタン、貼り付け（Ctrl+V）、ドラッグ＆ドロップでページに追加
  - 機能アイテム: **メモへ移動ボタン**（押すと別のメモファイルを開く）・**チェックボックス**（クリックした場所に置けます）・**プルダウン**（選択肢は自由に編集）
- **色**: よく使う色に加えて、パレットからたくさんの色、「その他の色」で自由な色を選べます（最近使った色も出ます）
- **タグ**: テキストボックス・付箋・チェックボックスに「タグを付ける」で付けるか、文字の中に `#タグ` と書くとタグになります。サイドバーにタグの一覧が出て、押すとそのタグのメモファイルを探せます（検索欄に `#タグ` と入れても同じ）
- **URL判定**: 文字の中の `https://…` や `www.…` はクリックできるリンクとして表示します（アイテムごとにオフにもできます）
- **元に戻す / やり直す**（Ctrl+Z / Ctrl+Y）
- **検索**: メモファイル名・ページの文字・タグ・フォルダ名・ボックス名から検索
- **表示**: グリッド / リストの切り替え、ライト / ダーク / 自動のテーマ
- **バックアップ**: 右上の「︙」から、画像も含めて JSON に書き出し・読み込み（以前の形式のバックアップも読み込めます）

ショートカット: `/` で検索。メモファイルの中では `V` 選択・`L` 範囲選択・`T` テキスト・`S` 付箋・`P` ペン・`M` マーカー・`G` 図形・`E` 消しゴム、`Delete` で選んだものを削除、`Esc` で選択解除。

入力した文字はそのまま保存されます。URL や #タグ は表示のときだけ見分けていて、保存される文字は変わりません。

## 以前のメモについて

カード型だった頃のメモは、初めて開いたときに自動で「マイボックス › 以前のメモ」へメモファイルとして移されます（ゴミ箱に入っていたものは除く）。チェックリストは ☐ / ☑ 付きの文字に、画像はページに貼られます。

## データの保存場所

メモと画像は、開いているブラウザの中（IndexedDB）にだけ保存されます。サーバーには送られません。

- 別の端末やブラウザとは共有されません。移したいときはバックアップを書き出して、移した先で読み込みます。
- ブラウザのサイトデータを消すとメモも消えます。大事なメモは時々バックアップを書き出してください。
