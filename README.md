# My notebook

メモや画像を自由に記録できるノートサイトです。Google Keep のようなカード型のメモアプリを参考にしています。

- サイト: https://lumiere2110.github.io/My-notebook/

## できること

- **メモ**: タイトルと本文。書いた文字はそのまま保存されます（Markdown やリンクなどの自動変換はしません）
- **画像**: ボタンから追加、画面へのドラッグ＆ドロップ、コピーした画像の貼り付け（Ctrl+V）。クリックで拡大表示・保存
- **チェックリスト**: 本文と一緒に項目を追加でき、完了した項目は下にまとまります
- **固定**: よく見るメモを一覧の上に固定
- **色**: 12色から背景色を選べます
- **ラベル**: メモにラベルを付けて、サイドバーから絞り込み
- **アーカイブ / ゴミ箱**: 一覧から片付ける・元に戻す・完全に削除
- **検索**: タイトル・本文・リスト・ラベルから検索
- **表示**: グリッド / リストの切り替え、ライト / ダーク / 自動のテーマ
- **バックアップ**: 右上の「︙」から、画像も含めて JSON に書き出し・読み込み

ショートカット: `/` で検索、`c` で新しいメモ、`Esc` で閉じる。

## データの保存場所

メモと画像は、開いているブラウザの中（IndexedDB）にだけ保存されます。サーバーには送られません。

- 別の端末やブラウザとは共有されません。移したいときはバックアップを書き出して、移した先で読み込みます。
- ブラウザのサイトデータを消すとメモも消えます。大事なメモは時々バックアップを書き出してください。
